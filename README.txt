RS Downloader - Android Studio project

What it does:
- Downloads direct HTTPS audio-file URLs (for example, MP3 files) that the user is authorized to save.
- Saves files in the device Downloads folder and uses Android's download notification.

Important:
- This app does not extract audio from YouTube or bypass platform restrictions.
- Use only audio files you own or have permission to download.

Build APK:
1. Install Android Studio (latest stable) on a computer.
2. Open this RSDownloader folder as a project.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location (usually app/build/outputs/apk/debug/app-debug.apk).

Application ID: com.rsdownloader.app
Minimum Android: 6.0 (API 23)
